# 党中央关于第二次世界大战时期国家总体战全局统筹的若干指导意见

## 1. 全局统筹

- 政治国策
    - 国策：优先消除负面 关注宣战契机 关注特殊事件
    - 决议：关注大选 和 意识形态
    - 顾问：关注顾问属性
    - 点数：政治点数、指挥点数、三军经验富余时，及时实施相应动作，避免点数溢出浪费

- 科研工作
    - 优先激活39年科技，优先制造、升级军工制造商
    - 创建装备衍生品时，可选择应用装备制造商，即可生效最新特质加成，即属性加成与研究时机无关
    - 科研设施：两空 + 陆 + 核 + 海
    - 优先科技
        - 步兵: 支援武器 步兵装备 机械化装备
        - 支援: 工兵 侦查 宪兵 医院 后勤 通信 装甲火车
        - 坦克: 基础装甲 基础引擎 中型坦克
        - 火炮: 火炮 防空炮 反坦克炮 火箭炮（火箭发射轨）
        - 飞机: 小型机身 机炮 摄像侦查 引擎（航程改进）
        - 工程: 电子工程 原子能 制导系统
        - 工业: 柔性生产线 密集型工业 建筑技术
        - 海军: 水雷战（空投水雷）
        - 专项: 前置按需

- 情报工作
    - 首要任务：国内反间谍（内部安全）
    - 次要任务：建立情报网（特工升级）
    
- 国家建设
    - 建设优先级：（补给中心 铁路 基础设施） - （实验设施 工厂 转换） - （核反应堆 要塞）
    - 生产优先级：（提升军工企业 售卖基础装备） - （装备设计生产） - （装备迭代）
    - 招募优先级：（普通部队招募训练 获取陆军经验） - （专业部队招募训练）

## 2. 三军建设

- 兵种学说
    - 陆军: 决战计划        卓越单兵        自行式支援      机动防御        大规模强袭
    - 海军: 贸易封锁        主力舰猎手      新战术学派      航母舰队集群    战列线
    - 空军: 战场支援        战斗轰炸机      空中火炮        战术级战场支援  地毯式轰炸
    - 特种: 精英特种部队    重视山地步兵    游骑兵丛林训练

- 将领
    - 将领经验升满后再点击特质，以免后续升级缓慢

- 装备设计
    - 保存位置: `Hearts of Iron IV\session_persistence\equipment_designs\equipment_designs.txt`
    - 坦克
        - 忽略生产花费 降低燃油使用 最大化各项参数
        - 最大速度（~= 6.4km/h） 可靠性（~= 100%）
        - 关注优势属性：坦克（均衡） 坦歼（对甲） 自火（对人） 防空（对空）

        - 通用配件：先进无线电 + 湿式弹药架 + 克里斯悬架 + 焊接装甲
        - 中型坦克：小型加农炮x2 + 柴油引擎
        - 现代坦克：倾斜装甲 + 锥膛炮转换 + 油电引擎
    - 空军
        - 忽略生产花费 降低燃油使用 最大化各项参数
        - 丰富可执行任务类别
        
    - 海军
        - 舰队编制:
            - 主力舰队: 航母x1 + 战列x1 + 轻巡x2 + 驱逐x2
            - 特种舰队: (潜艇、驱逐)x10
        - 海战寻敌: 巡逻舰队 (驱逐避战、潜艇勾引、护航勾引) + 打击舰队
        - 特别说明: 航速>30; 比例遵循 1:1:4

        - 航母CV: 满机库 + 基本生存 + 海轰 (侵略姿态) + 现代航母/冰航母
        - 战列BB: 主重炮 + 辅轻炮 + 重甲 + 基本速度 + 现代战列
        - 轻巡CL: 满轻炮 + 满装甲
        - 驱逐DD: 三选一 (生存|鱼雷|轻炮)
        - 潜艇SS: 满鱼雷 + 低可见 + 消声瓦 + 无氧推进 + 舰队潜艇
        - 不推荐: 战巡BC 重巡CA 雷巡 无畏舰 岸防舰 支援舰 维修舰

- 兵种编制
    - 降低装备类型（去除轻坦）
    - 主力师
        - 中坦师
            - 通用配置：团属（两摩重武+两中坦歼+一中防空） + 机械化支援（工兵+侦查+通信+后勤+医院）
            - 36宽：九步九坦（三中坦+三坦歼+三自火）
        - 装甲掷弹兵师
            - 通用配置：团属（三重武+两防空） + 支援（工兵+侦查+通信+后勤+医院）
            - 40宽：十二步八炮（四火炮+四反坦）
            - 30宽：九步六炮（三火炮+三反坦）
    - 功能师
        - 填线师
            - 说明: 人力不足时建议使用，按对手强度调整
            - 编制: 四步两支援（一炮+一工兵+一重武） 五步一炮 七步二炮 九步三炮
        - 宪兵师
            - 机制: 装备率 影响 驻军效率；驻军效率 影响 抵抗度（正向） 顺从度（反向）
            - 说明：苛刻配额；人数尽量少；通过禁用轻坦装备 控制 驻军效率在 60%
            - 编制: 一骑五坦（五轻坦+一宪兵+一工兵） 一骑六坦 二骑八坦

## 3. 控制台

```shell
tdebug              # 地图上显示调试信息
fow                 # 战争迷雾开关
observe             # ​观察者模式

tag <TAG>           # 控制指定国家
event <ID>          # 触发指定事件
add_ideas <ID>      # 添加民族精神
remove_ideas <ID>   # 移除民族精神

pp                  # 增加政治点
cp                  # 增加指挥点数
xp                  # 增加三军经验
mastery             # 增加学说精通度

roic                # 点击图标完成研究
sp_ra               # 完成所有特殊项目
sp_br 10            # 增加突破点

gain_xp <NUM>       # 为所选人物增加经验
addfunds            # 给军工机构添加经验

threat              # 添加全球紧张度
```
